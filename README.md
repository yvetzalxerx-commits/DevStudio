## Running code on a new device
  Install node.js "https://nodejs.org/en/download"
  refresh vs code application

  Open windows powershell as admin
  input `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`

## Running the website server (localhost)

  Run `npm i` to install the dependencies on a terminal.

  Run `npm run dev` to start the development server.

## Running the chatbot server

1. Navigate to src → server then right click server folder to open in terminal. 
2. Start the server: `node index.js`.
